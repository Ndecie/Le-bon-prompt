    Interrogatoire

    Direction artistique

    Voulez-vous choisir une direction artistique ?

    Le style visuel, la typographie et les couleurs de votre projet. Trois écrans, deux minutes. Si vous passez, l'IA choisira à votre place.

      Direction artistique · 1 sur 3

      Quel style visuel ?

      Cochez-en autant que vous voulez. Les vignettes sont dessinées dans l'esprit de chaque style.

        Direction artistique · 2 sur 3

        Quelle typographie ?

        Cochez-en autant que vous voulez. Chaque nom est écrit dans une police de sa famille : vous lisez le style en lisant son nom.

          Direction artistique · 2 sur 3

          Une police précise ?

          Chacune dans sa vraie police. Laissez « Peu importe » si vous préférez que l'IA tranche parmi les trois.

          Direction artistique · 3 sur 3

          Quelle palette de couleurs ?

          Cochez-en autant que vous voulez. Les codes hexadécimaux partiront tels quels dans le prompt.

            Avant-dernière étape

            Qu'est-ce qui trahirait que c'est l'IA qui a travaillé ?

            Cochez tout ce que vous ne voulez surtout pas voir apparaître. Sans limite. Ce que vous cochez deviendra une liste d'interdictions dans votre prompt ; ce que vous laissez décoché reste permis.

            Liste inspirée de @buildwithmathias.

            Dernière étape

            Vous voulez récupérer quoi, exactement ?

            Nommez le fichier que vous voulez au bout du compte, pas ce qu'il contient. C'est cette rubrique qui fera foi dans le prompt : si vous cochez PowerPoint, il réclamera un vrai fichier .pptx, et un script Python pour le fabriquer si l'IA ne sait pas livrer de fichier.
